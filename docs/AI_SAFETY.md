**Hackathon**: HackCBS 9.0  
**Authors**: Senior AI Safety Engineer, Staff Product Engineer  
**Status**: Ethical Baseline & Specification

## 1. Ethical Non-Negotiables

Artificial Intelligence in UMEED is designed strictly as an **amplification tool for human empathy and logistical speed**, never as an autonomous decision-maker for life-or-death situations.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        AI SAFETY GUARDRAILS                            │
├────────────────────────────────────────────────────────────────────────┤
│ 1. NO AUTONOMOUS DISPATCH                                              │
│    • AI models classify and suggest; an authorized human coordinator   │
│      MUST confirm or adjust dispatch for high-risk situations.         │
│                                                                        │
│ 2. NO AUTONOMOUS MEDICAL DIAGNOSIS                                     │
│    • Visible conditions are labeled as non-medical observations only.  │
│    • No pharmacological, clinical, or diagnostic advice is generated.  │
│                                                                        │
│ 3. FAIL-SOFT RESILIENCE                                                │
│    • System functions 100% manually if Gemini or Meko is unreachable.  │
│    • Quota exhaustion or model downtime never halts the review queue.  │
└────────────────────────────────────────────────────────────────────────┘
```

## 2. Gemini Multimodal Triage Architecture

When a citizen report or crawler payload arrives, the media and description are submitted to the Gemini Multimodal model using strict structured JSON schemas:

```json
{
  "incident_type": "injured_animal",
  "subject_type": "animal",
  "visible_trauma_observations": [
    "Compound fracture visible on right hind limb",
    "Active bleeding observed"
  ],
  "recommended_severity": "critical",
  "confidence": 0.94,
  "confidence_reasoning": [
    "High visual clarity of wound",
    "Subject positioned in direct traffic lane"
  ],
  "missing_information": [],
  "safety_advisories": [
    "Animal may be defensive due to severe pain; use gentle handling equipment"
  ]
}
```

### 2.1 Non-Diagnostic Labeling Standard
The UI explicitly renders all AI outputs behind clear informational alerts:
> [!NOTE]
> **AI Triage Suggestion — Non-Medical Observation**  
> *Identified: Visible canine limb trauma. This assessment was generated by an AI model to assist dispatch prioritization. It does NOT constitute a veterinary diagnosis.*

## 3. Human-in-the-Loop Review Gates

No incident advances to responder notification without passing through the human coordinator verification gate:

1. **Side-by-Side Review**: Coordinators view raw uploaded evidence on the left and structured Gemini recommendations on the right.
2. **Override Authority**: Coordinators have full authority to downgrade or upgrade severity, correct subject types, or discard hallucinations.
3. **Audit Provenance**: If a coordinator overrides the AI recommendation, the reason (e.g., *"Photo shows old scar tissue, not acute bleeding"*) is immutably recorded in `review_actions` for continuous model evaluation.

---

## 4. Resilience & Fallback Protocols

If the Gemini API encounters timeouts, network errors, or rate limits:
1. The incident is immediately marked with `ai_triage_status: "UNAVAILABLE"`.
2. The severity defaults to `unconfirmed` with `requires_human_review: true`.
3. The queue displays an accessible warning badge: *"AI Triage Offline — Coordinator Manual Verification Required"*.
4. **Zero Pipeline Halting**: Citizen reporting and coordinator dispatch continue uninterrupted.

---

## 5. Algorithmic Fairness in NGO Matching

To prevent preferential bias or regional neglect in dispatching assistance:
- Matching is governed by an **objective, deterministic mathematical formulation** ($w_s S_{\text{capability}} + w_g S_{\text{geography}} + w_a S_{\text{availability}} + w_c S_{\text{capacity}} + w_h S_{\text{history}}$).
- Proximity alone is not decisive; capability is a binary hard filter ($S_{\text{capability}} \in \{0, 1\}$).
- The exact scoring breakdown is rendered transparently in the Coordinator UI, preventing hidden algorithmic favoritism.
